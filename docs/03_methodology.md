## 2. 收益率曲线的表示：官方 Hermite vs NS/NSS

### 2.1 两个不同的东西

| | 官方曲线 | 我们的 NS/NSS |
|---|---|---|
| 来源 | 中债估值中心，**Hermite 三次插值** | 我们自己拟合 |
| 作用 | 定价基准（成品） | **参数化降维**，用于求导、因子、情景 |
| 维度 | 11 个离散点 | 4（NS）或 6（NSS）个参数 |

**关键认识**：中债曲线已经平滑，所以 NS/NSS **不是插值**，而是把 11 个点压缩成少数参数，以获得：
1. **可解析求导** → 算瞬时远期、KRD、情景冲击；
2. **可解释因子** → level / slope / curvature；
3. **降噪** → 单个期限点的异常报价不会污染信号。

### 2.2 三种插值/表示的关系

```
官方 11 点  ──Hermite──▶  官方曲线（平滑、离散点之间光滑）
    │
    └──NS/NSS 拟合──▶  参数曲线（低维、可解析）
                         │
                         └──▶ 因子暴露、KRD、情景冲击
```

实现上 `Curve` 对象同时支持 `linear` / `hermite` / `ns` / `nss` 四种 `method`，
但**下游默认使用 NS/NSS**，因为只有它有解析导数。

### 2.3 外推策略

回测中持仓期限一般落在 $[0.25, 30]$ 内，不做首尾外推。若必须外推（如 30Y 以上做压力测试）：

- 短端：线性延伸到 0，但**不允许为负**；
- 长端：保持最后一段斜率，同样 **clamp 到 ≥ 0**。

> 原因：负利率在中国国债上不现实，出现负值一定是数据或拟合错误，宁可 clamp 并报警。

### 2.4 即期（零息）曲线的 bootstrap —— 合成假设必须显式声明

**为什么需要它**：中债公开批量下载的只有**到期收益率（YTM）曲线**；而现金流贴现、远期利率、关键期限久期（KRD）都需要**即期（零息）曲线**。两者不能混用：YTM 是"一只票息债的内部收益率"，即期是"零息利率"，对同一期限前者通常低于后者（正常向上曲线下）。

**这是一个"合成"过程，不是观测**。所有假设必须写进代码、写进 `SpotCurve.assumptions`、写进报告：

| # | 假设 | 内容 | 为什么这样定 |
|---|------|------|--------------|
| A1 | 平价债券 | 把曲线每个期限点 $\tau$ 视为一只**平价债券**：票面 $C=y(\tau)$、价格 $=100$ | 中债曲线本身就是按"样本券到期收益率"编制的，在 $\tau$ 点以平价债解释是标准做法 |
| A2 | 付息频率 | $<1$Y：零息（单笔现金流）；$1\text{–}7$Y：年付；$10/30$Y：半年付 | 与中债实际国债条款一致（见 `docs/00_market_conventions.md` 结论 5） |
| A3 | 短端贴现 | $<1$Y 用**单利** $df(t)=\dfrac{1}{1+y\,t}$ | 货币市场惯例；与中债短端报价口径一致 |
| A4 | 长端贴现 | $\ge 1$Y 用**分频复利** $df(t)=\left(1+\frac{y}{f}\right)^{-f t}$ | 与 `ficc.pricing.bond` 的中债估值公式同口径，保证可对账 |
| A5 | 节点间插值 | 已知零息点之间按**零息利率线性插值** | 简单、无套利、可复现；远期插值会在节点处引入不稳定跳变 |
| A6 | 结算 | 曲线估值日 **T+1** 结算 | 银行间现券 DVP T+1 |
| A7 | 外推 | 超出最后一个期限点后**零息利率平推（flat）** | 避免外推段产生虚假的远期波动 |

**算法**（逐个期限点顺序求解）：

设第 $k$ 个期限 $\tau_k$ 的平价债有 $n_k$ 次付息，付息日 $t_{k,1}<\dots<t_{k,n_k}=\tau_k$，票息 $c_k=y(\tau_k)/f$：

$$100=\sum_{i=1}^{n_k} c_k\cdot df(t_{k,i}) + 100\cdot df(\tau_k)$$

其中 $t_{k,i}<\tau_k$ 的 $df$ 由**已求出的较短期限零息点**插值得到（假设 A5），只剩 $df(\tau_k)$ 一个未知数，解出：

$$df(\tau_k)=\frac{100-\sum_{i<n_k} c_k\,df(t_{k,i})}{100+c_k}\qquad\Longrightarrow\qquad z(\tau_k)=\frac{-\ln df(\tau_k)}{\tau_k}$$

**验收标准（硬性）**

1. **往返一致性**：用 bootstrap 出的即期曲线重估每个合成平价债，价格必须 $=100\pm10^{-8}$。这是 bootstrap 正确性的直接证据，任何插值/口径错误都会在这里暴露。
2. 正常向上曲线下：$z(\tau)\ge y(\tau)$（息票效应），且远期利率 $\ge$ 即期利率。
3. $df(t)$ 严格递减且 $>0$；曲线倒挂时允许负远期，但必须记录。
4. 平坦曲线（$y$ 为常数）时 $z(\tau)=y$ 对所有 $\tau$ 成立（解析解）。

**局限（必须写进报告）**

- 这是**从估值曲线反推的合成即期曲线**，不是官方发布的即期曲线，也不是真实成交结果；
- 假设 A1（平价）意味着忽略了样本券的真实票面与剩余期限分布，因此短端与超长端的即期曲线误差更大；
- A5（线性插值）会让零息曲线在节点处有折点，二阶量（凸性、KRD 的交叉项）对插值方式敏感——所以 KRD 的验收必须同时检查"各 KRD 之和 ≈ 总 DV01"。

**实测验收结果**（模块 `src/ficc/curve/bootstrap.py`，假设全部记录在 `SpotCurve.assumptions`）：

| 检查 | 要求 | 实测 |
|------|------|------|
| 往返一致性（3 个代表日：2024-06-28 / 2013-06-20 / 2026-11-05） | $=100\pm10^{-8}$ | **最大误差 2.84e-14** |
| 平坦曲线解析解 | $z=y$ | 精确复现（年付 $z=100\ln(1+y/100)$；<1Y 单利 $z=100\ln(1+yt)/t$） |
| 向上曲线 $z(\tau)\ge y(\tau)$ | 成立 | 成立 |
| 倒挂日 2013-06-20 | 允许负远期并记录 | 短端≈5.0%、长端≈4.2%，远期有限、discount 严格递减 |

## 3. Nelson-Siegel / Svensson 拟合

### 3.1 Nelson-Siegel（4 参数）

$$y(t)=b_0+b_1\frac{1-e^{-t/\tau}}{t/\tau}+b_2\left[\frac{1-e^{-t/\tau}}{t/\tau}-e^{-t/\tau}\right]$$

- $b_0$：长期水平（$t\to\infty$ 的收益率）；
- $b_1$：短端与长期的**斜率**（通常为负，即短低长高时 $b_1<0$）；
- $b_2$：**曲率**（驼峰强度）；
- $\tau$：决定驼峰位置。

### 3.2 Svensson（6 参数）

$$y(t)=b_0+b_1\frac{1-e^{-t/\tau_1}}{t/\tau_1}+b_2\left[\frac{1-e^{-t/\tau_1}}{t/\tau_1}-e^{-t/\tau_1}\right]
+b_3\left[\frac{1-e^{-t/\tau_2}}{t/\tau_2}-e^{-t/\tau_2}\right]$$

多一个驼峰，能刻画 2011/2013 年那种长端"双驼峰"形态。

### 3.3 数值稳定性：$t\to 0$ 的处理

$$\frac{1-e^{-x}}{x}\xrightarrow{x\to 0}1-\frac{x}{2}+\frac{x^2}{6}-\cdots$$

代码里用 `np.where(x > 1e-8, (1-exp(-x))/x, 1 - x/2 + x**2/6)`，避免 0/0。

### 3.4 优化问题

$$\min_{\theta}\ \sum_{i} w_i\left[y_i-\hat y(t_i;\theta)\right]^2$$

| 项 | 设置 | 理由 |
|----|------|------|
| 权重 $w_i$ | `inverse_maturity_bucket`：短端权重更高 | 短端是资金面与政策的直接反映，噪声也大；且短端对曲线交易更关键 |
| 边界 | $b_0\in[0,20]$，$b_1,b_2\in[-20,20]$，$\tau\in[0.05,30]$ | 防止数值爆炸到无意义区域 |
| 多起点 | $\tau_0\in\{0.5,1,2,4,8\}$ | NS/NSS 目标函数非凸，单起点会掉进局部极小 |
| 求解器 | `scipy.optimize.least_squares`（`trf`） | 支持边界、对残差平方和稳健 |
| 失败处理 | 记录 `success=False`，**不静默剔除** | 拟合失败日必须进入质量报告 |

### 3.5 残差与验收标准

残差定义为 $\varepsilon_i = \hat y(t_i)-y_i$（**单位 bp**，即 $(\hat y-y)\times 100$）。

| 指标 | 预期 | 含义 |
|------|------|------|
| 平均绝对残差（MAE） | < 3bp | 拟合能力（**须在本轮有界求解器修复后重新验收**） |
| 95 分位绝对残差 | < 8bp | 尾部（曲线畸变日） |
| 残差均值 | ≈ 0 | 无系统性偏差 |
| 残差自相关 | 弱 | 若强，说明曲线有 NS/NSS 表达不了的结构 |

> **残差本身就是研究结论**，但**必须先排除求解器误差**再解释：早期版本用"无约束最小二乘 + 系数裁剪"，
> 导致极端日的残差被数值方法放大（例如 2002-04-26 由 156.0bp 降到 93.8bp）。只有使用真正的有界最小二乘后，
> "残差大的日期对应极端行情"才能作为模型局限的证据。

## 4. 因子分解：水平 / 斜率 / 曲率

### 4.0 结论先行：交易与归因用**可观测因子**，模型参数只作研究诊断

经过评审（R02）后的定稿口径：

| 用途 | 用什么 | 原因 |
|------|--------|------|
| **策略信号 / 风险归因 / 报告** | **可观测因子**（直接由期限收益率构造） | 无识别性问题、可复现、可解释，且与交易台语言一致 |
| 曲线形状刻画、情景冲击、KRD 前置 | NS/NSS **拟合曲线** | 需要连续可导的曲线 |
| 研究诊断、论文式讨论 | NS/NSS **参数** | 有经济含义，但**不可直接当因子用**（见 §4.4 实测反例） |

**可观测因子定义**（本项目采用，代码见 `src/ficc/curve/factors.py`）：

$$
\text{level}_t = \frac{1}{4}\left(y^{10}_t+y^{15}_t+y^{20}_t+y^{30}_t\right),\qquad
\text{slope}_t = y^{10}_t-y^{2}_t,\qquad
\text{curvature}_t = 2y^{5}_t-y^{2}_t-y^{10}_t
$$

- `level` 与锚定 $b_0$ 的定义一致（长端均值），因此两者可互相校验；
- `slope` 用 10Y−2Y 利差，就是曲线陡平交易的标的本身，**不需要任何模型**；
- `curvature` 用 2×5Y−2Y−10Y（蝶式的标准定义）。

### 4.1 另外两种做法（保留但降级为辅助）

| 做法 | 做法细节 | 定位 |
|------|----------|------|
| **NS/NSS 参数** | 取 $b_0,b_1,b_2$ | **研究诊断**，不直接作因子 |
| **PCA** | 对 $\Delta y_{t,\tau}$ 做特征分解 | 用于验证可观测因子的解释力与正交性 |

用 PCA 验证可观测因子是否与主成分方向一致（例如 `level` 与 PC1 的相关系数应 > 0.95），是**交叉校验**而非替代。

### 4.2 PCA 定义

设 $\Delta y_t\in\mathbb{R}^{11}$ 为 $t$ 日各期限收益率变化（bp），样本矩阵 $X\in\mathbb{R}^{n\times 11}$（已去均值）：

$$X = U\Sigma V^\top,\qquad \text{载荷}=V,\quad \text{得分}=U\Sigma$$

- 第 1 主成分（PC1）：**水平**（所有期限同向），解释方差通常 > 80%；
- 第 2 主成分（PC2）：**斜率**（长短端反向），通常 5–15%；
- 第 3 主成分（PC3）：**曲率**（两端与中间反向），通常 2–8%。

### 4.3 因子暴露

组合对因子的暴露用**回归**得到：

$$\Delta y_{\text{portfolio},t} = \alpha + \beta_1 f_{1,t} + \beta_2 f_{2,t} + \beta_3 f_{3,t} + \epsilon_t$$

其中 $\Delta y_{\text{portfolio}}$ 可用组合的 DV01 加权平均收益率变化近似。$\beta$ 就是组合的因子暴露，
也是**收益归因**的输入。

### 4.4 验收标准

- PC1+PC2+PC3 累计解释方差 **> 95%**（若不足，说明曲线形态异常或有数据问题）；
- 载荷符号与直觉一致（PC1 全正、PC2 长正短负、PC3 中间与两端反向）；
- **所有实际使用的因子都必须通过跳变检验**：相邻日变化的分布、p99、最大跳变日期（见 §4.5）。

### 4.5 模型参数的识别性陷阱（本项目实测，务必不要再犯）

NS/NSS 在 11 个期限点上是**参数不可识别**的：存在多组差异巨大的参数给出几乎相同的拟合。
本项目实测到的两个反例（评审 R02）：

| 日期 | 市场变化 | 参数变化 | 问题 |
|------|----------|----------|------|
| 2023-10-11 → 10-12 | 各期限收益率最大变动仅 **0.04 个百分点（4bp）** | $b_0$: 2.843725 → 2.839150（稳定）<br>**$b_1$: −2.395903 → −0.922731（跳 147.32bp）**<br>$\tau_1$: 0.222 → 1.5，$\tau_2$: 0.481 → 30 | 市场几乎没动，slope 因子跳了 147bp |
| 全样本 | — | $|\Delta b_1|$ 的 p99 = **0.8995 个百分点** | b1 不可直接投入信号 |

**因此定下三条纪律**：

1. **不要用 $b_1$ 当 slope 因子**——用 10Y−2Y 利差；
2. **不要用 $b_0$ 的稳定性去论证其他参数稳定**——$b_0$ 之所以稳，是因为"长端观测均值锚定"这个人为约束，
   它证明的是约束生效，不是识别性恢复；
3. 若一定要用模型参数，必须用**因果**方案：在训练窗口内确定并**冻结** $\tau$，或用状态空间/Kalman 做前向滤波；
   **任何时候都不允许用 $t$ 之后的数据做平滑**。

> 补充：求解器本身也会影响结论。早期实现用"无约束最小二乘 + 系数裁剪"，
> 极端日的残差被数值方法放大（2002-04-26 由 156.0bp → 有界求解后 93.8bp）。
> 所以"残差大 = 模型局限"这个推论，必须先排除求解器误差。

### 4.6 自由拟合与锚定拟合是**两个产品**，必须分别验收

| 产品 | 定义 | 用途 | 全样本 NSS RMSE 中位（实测） |
|------|------|------|------------------------------|
| **自由拟合（free）** | 所有参数在边界内自由求解 | 衡量模型**表达能力上限**、残差诊断、错价发现 | 3.3328 bp |
| **锚定拟合（anchored）** | $b_0$ 由长端观测锚定，其余有界求解 | 提供**稳定的 level 口径**与可重建曲线 | 4.7586 bp |

**禁止**用自由拟合的 3.33bp 去背书锚定曲线的精度；**也禁止**说"锚定只是同一条曲线换一组参数"——
锚定改变拟合曲线本身（2013-06-20 两者 RMSE 分别为 2.6248 / 10.8484bp）。
两套产品的参数、拟合值、残差、误差指标必须分别落盘、分别引用。

### 4.7 实测：PCA 与可观测因子的对齐情况（**含一个未达标的结论**）

样本：$\Delta y$（bp），11 个期限，2002-01-04 → 2026-11-05。三种口径：全样本、±10bp winsor、250 日走前滚动。

| 口径 | level↔PC1 | slope↔PC2 | curvature↔PC3 |
|------|-----------|-----------|---------------|
| 全样本 | **0.297** | 0.324 | 0.022 |
| 全样本 + winsor ±10bp | 0.326 | 0.750 | 0.320 |
| 滚动 250 日（走前） | 0.060 | 0.426 | 0.227 |

**验收目标（level↔PC1 > 0.95）未达成。如实记录，不调整定义去凑数。** 原因已经定位：

1. **定义错位**：本项目的 `level` 定义为**长端均值**（10/15/20/30Y），而中国国债曲线的 PC1 主要由**短端资金面波动**驱动。诊断性验证：把 level 定义为**全期限均值**（`level_all`）后，与 PC1 的相关系数变为 **0.929 / 0.863 / 0.802**（全样本/winsor/滚动）——证明问题在定义，不在 PCA。
2. **数据异常放大**：2002–2009 存在官方文件的孤立跳变点（例如 30Y 在 2002-04-26 为 10.54%、次日 2.76%），单日数百 bp 的假变化会把 PC1 拉向噪声；winsor ±10bp 后 PC1 解释方差由 0.60 降到 0.46，说明原 PC1 里有相当部分是异常点贡献。

**因此修正因子口径（最终采用）**：

| 因子 | 定义 | 用途 |
|------|------|------|
| `level_all` | 全期限（11 点）均值 | 与 PC1 对齐的**平行移动**因子；曲线平移归因 |
| `level_long` | 10/15/20/30Y 均值 | 长端估值锚（与锚定 b0 定义一致），用于 carry/roll 语境 |
| `slope` | 10Y − 2Y | 陡平交易标的，无需模型 |
| `curvature` | 2×5Y − 2Y − 10Y | 蝶式 |

- 正交化（slope 对 level 回归取残差、curvature 对 level+slope 回归取残差）后，三个因子相关性降到 **< 1e-10**，可安全用于并列归因；
- **PCA 载荷不稳定**：滚动 250 日口径下载荷时变明显（这也是"不要把 PCA 载荷当固定参数"的理由），因此策略/归因用**可观测因子**，PCA 只做交叉校验。

> 结论：**"level 因子"在本项目里必须区分 `level_all` 与 `level_long`**。前者对齐 PC1、后者对齐锚定 $b_0$。
> 混用会导致"因子暴露"与"曲线平移归因"对不上账。

### 4.8 10Y 系统性偏差的持续性（决定"能不能当错价交易"）

NSS 自由拟合在 10Y 的残差均值约 **+4.63bp**（MAE 5.15bp、88.9% 交易日为正）。评审要求先查清它是否持续，再决定能否作信号。实测结论：

| 检验 | 结果 | 含义 |
|------|------|------|
| t 检验（均值=0） | t=86.1，p≈0 | 偏差高度显著 |
| ADF（单位根） | p=0.0011，拒绝 | 残差平稳（不是随机游走） |
| KPSS（常数均值） | p=0.010，拒绝 | **均值本身随时间漂移**，没有稳定锚 |
| AR(1) | φ=0.884，半衰期 **5.63 日** | 短期偏离一周内衰减；但慢变分量持续 |
| 分段均值 | +2.23 / +3.34 / +7.16 / +5.66bp（2002–07 / 08–13 / 14–19 / 20–26） | 制度性漂移，区间宽 4.9bp |

**一句话结论：10Y 是"持续性溢价"（结构性偏贵），但不是可直接交易的错价。**

理由：① 分段均值漂移无稳定锚，无法定"公允价值"；② NSS 只是低维平滑，不是无套利定价，残差是**模型相对量**；③ 静态做多/做空该溢价要承担负 carry 与不可控的期限风险；④ |mean|/MAE = 0.90，扣除往返成本后空间有限。

**允许的用法**：作为估值/对冲的**中性化调整项**（例如 KRD 归因时把 10Y 的常驻偏差剥离），或继续研究"相对滚动均值的短期偏离"（需另做 z-score 与状态空间估计，本轮不做）。**禁止**把它直接当作"10Y 被低估/高估"的信号。

## 5. 曲线情景冲击

给定基准曲线 $y(\tau)$ 与冲击幅度 $\delta$（bp），定义：

| 情景 | 定义 | 用途 |
|------|------|------|
| 平行移动 `parallel` | $y'(\tau)=y(\tau)+\delta$ | 利率风险（DV01 天然对冲） |
| 陡峭化 `steepen` | $y'(\tau)=y(\tau)+\delta\cdot\frac{\tau-\bar\tau}{\tau_{\max}-\bar\tau}$，$\bar\tau$ 为曲线重心 | 长端上行、短端不动 |
| 平坦化 `flatten` | 上式取 $-\delta$ | 长端下行 |
| 蝶式 `butterfly` | $y'(\tau)=y(\tau)+\delta\cdot g(\tau)$，$g$ 在中间期限取正、两端取负（或相反） | 曲率风险 |

实现要求：
- 冲击后曲线**不得出现负利率**（clamp 并记录警告）；
- **历史情景**用真实历史曲线变化重演：取事件窗口内的 $\Delta y_t$ 实际值，而不是人为构造。

历史情景（已写入 `config.yaml`）：

| 情景 | 窗口 | 为什么选它 |
|------|------|-----------|
| 2013 钱荒 | 2013-05-20 → 2013-06-20 | 短端飙升、曲线极端平坦化 |
| 2020 疫情 | 2020-01-20 → 2020-04-30 | 快速下行 + 陡峭化 |
| 2022 理财赎回潮 | 2022-11-01 → 2022-12-31 | 流动性冲击 + 超调，最贴近银行现实的负尾风险 |

## 6. 定价：全价、净价、应计利息

### 6.1 三个价格的关系（唯一正确版本）

$$\boxed{\text{全价} = \text{净价} + \text{应计利息}}$$

- **报价**用净价（市场惯例）；
- **结算与 PnL、久期、DV01** 一律用**全价**。

> 用净价算收益是这类项目最典型的硬伤：付息前应计利息可达 0.8 元/百元面值，误差 0.8%。

### 6.2 中债估值公式（到期收益率口径）

设结算日 $s$，当前付息周期实际天数 $TS$，结算日至**下一个**付息日天数 $T$，$w=T/TS$，
剩余付息次数 $n$，票面 $C$，付息频率 $f$，面值 $M=100$：

$$PV=\sum_{i=1}^{n}\frac{C/f}{(1+y/f)^{\,i-1+w}}+\frac{M}{(1+y/f)^{\,n-1+w}},\qquad PV=\text{全价}$$

> ⚠️ **最容易写错的一行**：$w=T/TS$ 中的 $T$ 是「结算日 → **下一个**付息日」的天数。
> 若误用「距上一个付息日」的比例，刚起息时价格会错 0.5 元以上。

### 6.3 应计利息三分支

| 类型 | 公式 | 适用 |
|------|------|------|
| 规则附息 | $AI=\frac{C}{f}\cdot\frac{t}{TS}$ | 多数国债（2/3/5/7Y 年付、10/30Y 半年付） |
| 利随本清 | $AI=K\cdot C+C\cdot\frac{t}{TY}$ | 1Y 国债（到期一次还本付息） |
| 贴现/零息 | $AI=100-\frac{P_d}{T}\cdot t$ | 91D / 182D 贴现国债 |

其中 $t$ 为「上一付息日 → 结算日」实际天数（**算头不算尾**），$TY$ 为当前计息年度实际天数。

### 6.4 日计数基准

| 市场 | 基准 | 闰年 2/29 |
|------|------|-----------|
| 银行间 | ACT/ACT | **计息** |
| 交易所 | ACT/365 | **不计息** |

跨市场混用会在付息日前后产生"假跳空"与假信号，因此 `pricing.day_count` 与 `day_count_exchange` 分开配置。

### 6.5 由净价反解收益率

$$y^\*=\arg\min_y\left|\text{Clean}(y;s)-P_{\text{clean}}^{\text{market}}\right|$$

用 `scipy.optimize.brentq` 在 $[-0.05, 0.30]$ 上求根（允许轻微负利率，覆盖极端情形）。

> 官方算例校验：26 附息国债 10 @ 2026-05-28，给定净价取整到 **100.00** 反解得到 1.719974%，
> 与 1.72% 相差 **0.0026bp**——这个差来自**净价取整到分**，不是求根算法的收敛误差（求根精度单独断言）。

## 7. 风险指标：久期、凸性、DV01、KRD

### 7.1 定义（全部基于全价）

| 指标 | 公式 | 单位 |
|------|------|------|
| 麦考利久期 | $D_{mac}=\dfrac{\sum_i t_i\cdot PV_i}{PV}$ | 年 |
| 修正久期 | $D_{mod}=\dfrac{D_{mac}}{1+y/f}$ | 年 |
| 凸性 | $\Gamma=\dfrac{\sum_i t_i\left(t_i+\frac{1}{f}\right)PV_i}{PV(1+y/f)^2}$ | 年² |
| DV01 | $\text{DV01}=PV_{\text{全价}}\times D_{mod}\times 10^{-4}$ | 元/百元面值/bp |
| KRD | 对 $y(\tau_k)$ 单点 +1bp、其余点按插值联动，重估的 $\Delta PV$ | 元/百元面值/bp |

价格-收益率二阶近似：

$$\frac{\Delta P}{P}\approx -D_{mod}\Delta y+\frac{1}{2}\Gamma(\Delta y)^2$$

### 7.2 DV01 的量级感（来自实测算例）

| 券 | 修正久期 | DV01（元/百元面值/bp） | DV01（万元/亿面值/bp） |
|----|----------|------------------------|------------------------|
| 10Y（票面 1.72%，半年付） | 9.12 | 0.0912 | 9.1 |
| 30Y（票面 2.38%，半年付） | 21.18 | 0.2291 | 22.9 |

> **同样 DV01 限额下，30Y 只能拿 10Y 约 40% 的仓位**——这是久期风险预算最直观的体现。

### 7.3 KRD 的正确算法（不能用"总 DV01 × 期限占比"糊弄）

1. 由 YTM 曲线 **bootstrap 出即期（零息）曲线**（见 §2.4）；
2. 对第 $k$ 个关键期限点把零息利率加 1bp，其余关键点不动，**关键点之间按零息利率线性插值**、两端平推（flat）；
3. 用新的即期曲线**重估全部现金流** $PV_k$（不是解析近似）；
4. $\text{KRD}_k=PV_k-PV_0$（元/百元面值/bp；多头、收益率上行时为负）；
5. 校验：$\sum_k \text{KRD}_k\approx \text{DV01}_{\text{spot}}$（相对误差 < 1e-3），并与 YTM 口径 `dv01()` 对照（相对差 < 2%）。

**实现与实测**（模块 `src/ficc/pricing/analytics.py::key_rate_durations`，即期曲线为鸭子类型接口 `times / zero_rate(t) / discount(t)`）：

| 检验对象 | 关键期限 | sum(KRD) | DV01(YTM) | 相对差 |
|----------|----------|----------|-----------|--------|
| 260010.IB（10Y / 1.72% / 半年付）@2026-05-28 | 1/2/3/5/7/10/15/20/30Y | −0.091961 | −0.091217 | **0.82%** |
| 合成平价 10Y @2026-11-05 | 同上 | −0.092737 | −0.092053 | 0.74% |
| 合成平价 30Y @2026-11-05 | 同上 | −0.223740 | −0.223478 | 0.12% |

- 10Y 券的 KRD **98% 集中在 10Y 桶**（−0.085451 / −0.091961），符合"现金流集中在到期附近"的预期；
- `sum(KRD)` 与平行即期冲击的 DV01 相对差 ~1e-5 量级（内部固定 1bp 步长，无外部步长误差）；与 YTM 口径差 0.1–1.3% 来自**单一 YTM 久期 vs 即期零息曲线 + 复利口径**，已在 docstring 说明，不是错误。

## 8. Carry 与 Roll-down 分解

### 8.1 定义（持有期 $h$，通常 $h=1$ 日或 1 年）

$$\underbrace{\text{Carry}}_{\text{票息} - \text{融资成本}}+\underbrace{\text{Roll-down}}_{\text{曲线不变，期限缩短的价格效应}}+\underbrace{\Delta\text{Curve}}_{\text{曲线本身变化}}=\text{总收益}$$

**Carry（持有收益）**：

$$\text{Carry}\approx \left(y-\text{repo}\right)\cdot\frac{h}{365}$$

**Roll-down（骑乘/滚降）**：

$$\text{Roll-down}\approx -\left[y(\tau-h)-y(\tau)\right]\cdot D_{mod}(\tau)$$

> ⚠️ **最经典的算错**：10Y 持仓持有 1 年，滚动目标是 **9Y**，不是 7Y。
> 用 7Y 算会高估 0.91 个百分点（实测：9Y 口径 0.46%/年 vs 7Y 口径 1.37%/年）。

### 8.2 量级参考（2026-05-28 曲线：10Y=1.72%、9Y≈1.67%、DR007≈1.32%）

| 来源 | 计算 | 年化 |
|------|------|------|
| Carry | $1.72\%-1.32\%$ | +0.40% |
| Roll-down | $-(1.67\%-1.72\%)\times 9.12$ | +0.46% |
| **合计（曲线不动）** | | **≈ +0.86%** |

结论：**曲线不动时，10Y 持有一年大约赚 0.86%**；而曲线平行上移 10bp 就亏 $9.12\times 10\text{bp}=0.91\%$，
把 carry+roll 全部吃掉。这就是为什么回测必须把"平移"与"形态不变"分成两个情景。

### 8.3 实现约定

- `roll_down_step_years`（配置）= 1.0：滚动目标为 $T-1$ 年；
- Roll-down 的曲线形状**必须用同一时点**的曲线计算，不能跨期混用（否则引入未来信息）；
- 分解恒等式在单测中校验：$\left|\sum\text{分解项}-\text{实际 PnL}\right|<1\text{bp/日}$。

**实测（模块 `src/ficc/pricing/carry.py`）**

T−1Y 目标的量级证据（曲线 1.5% + 5bp/年，融资 2%，持有一年）：

| 滚动目标 | roll | 说明 |
|----------|------|------|
| **9Y（正确，T−1Y）** | **+0.4109%** | $y_9=1.95\%$、$D_{mod}(9)=8.2179$，与独立手算相对误差 1e-10 |
| 7Y（常见错误） | +0.9764% | **高估 0.5655pct** |

- 平坦曲线（3%）+ 融资 2% → carry = **1.0000%**、roll = 0（教科书校验）；
- 事后分解恒等式：+25bp 平行冲击下 `carry 0 + roll 0.4109 + level −2.0582 + shape 0 + residual 0.0224 = total`（误差 0，< 1bp）；陡峭/蝶式冲击 residual 分别 0.0024 / 0.0026；
- 真实数据横截面（2019–2026 采样，融资用 FDR007）：年化 carry/roll 均值 —— 5Y `+0.458 / +0.319`、10Y `+0.654 / +0.065`、30Y `+1.104 / +0.211`（%），见 `reports/carry_roll_table.csv`；
- **限制**：2Y 的 T−1Y 目标落在 1Y 及以下（利随本清/贴现券，无期间票息），无法做 carry/roll 分解，故横截面从 3Y 起算；需要 2Y 时须改用 `roll_years=0.5` 并单独说明。

## 9. DV01 中性组合构造

### 9.1 三种"中性"的区别（实测数字，2026-05-28 曲线，10Y 端 1 亿面值）

| 构造 | 面值比 | 净 DV01 暴露 | 平行上移 1bp 的 PnL |
|------|--------|--------------|---------------------|
| 名义本金中性 | 1 : 1 | **7.35 万元/bp** | −7.35 万元 |
| DV01 中性 | **1 : 5.16** | ≈ 0 | ≈ 0 |
| 久期中性（全价加权） | 1 : 5.16 | ≈ 0 | ≈ 0 |

> **不要把"名义本金中性"当"无风险"**：它残留 7 万元/bp 的久期暴露，10bp 反弹就是 70 万亏损。
> 真正的曲线交易必须 **DV01 中性**。

### 9.2 组合权重求解

设目标 DV01 为 $D^\*$，曲线交易对为 $(\tau_s,\tau_l)$（短/长）：

$$w_l\cdot\text{DV01}_l+w_s\cdot\text{DV01}_s=0,\qquad w_l\cdot\text{DV01}_l=D^\*$$

解：

$$\boxed{w_l=\frac{D^\*}{\text{DV01}_l},\qquad w_s=-\frac{D^\*}{\text{DV01}_s}}$$

### 9.3 国内约束：现券不能裸卖空

银行自营账户基本不做空，因此第一版用 **组合内相对超配/低配**：
在总 DV01 预算内，$w_l$ 加杠杆、$w_s$ 减配，整体仍为多头。期货空头腿（T/TF/TS）作为 Phase 3 扩展。

### 9.4 DV01 中性不是零风险

DV01 中性只对冲**一阶平行移动**。残留风险包括：

- **KRD 敞口**（曲线非平行变动）；
- **凸性差异**（大冲击时非线性）；
- **滚降路径**（持有期内期限缩短带来的收益不等于零）；
- **基差/流动性折价**。

因此报告必须同时展示 **KRD 向量**与**情景 PnL**，否则就是自欺欺人。

## 10. 回测约定与收益归因

### 10.1 时序纪律

```
T 日收盘  →  用 as_of <= T 的数据生成信号
T+1 日    →  按 next_close/next_open 成交，立即计成本
```

- `signal_lag_days = 1` 是硬约束，由 `MarketSnapshot` 强制时间切片实现；
- 对抗性测试：把未来数据打乱/置空，回测结果必须**完全不变**。

### 10.2 PnL 恒等式

$$\Delta NAV_t=\underbrace{\sum_i n_i\cdot\Delta P^{\text{full}}_{i,t}}_{\text{价格变动}}+\underbrace{\text{票息收入}}_{\text{付息日}}-\underbrace{\text{融资成本}}_{\text{repo}\cdot\text{市值}\cdot\frac{1}{365}}-\underbrace{\text{交易成本}}_{\text{手续费}+\text{价差}}$$

### 10.3 收益归因（每日必须可分解）

$$\text{总收益}=\text{Carry}+\text{Roll-down}+\text{Level}+\text{Slope}+\text{Curvature}+\text{Residual}$$

- Carry / Roll-down：按 §8 定义，用组合加权；
- Level/Slope/Curvature：用 §4 的因子暴露 $\beta$ × 当日因子变化；
- Residual：残差项（含成本、拟合误差、基差）。

**验收**：$\left|\sum-\text{实际}\right|<1\text{bp/日}$（单测 `test_carry.py`）。

> 判断一个策略是不是"真曲线策略"的标准：
> 若 Level 贡献占超额收益 > 80%，那它本质上只是久期暴露，报告必须写明。

### 10.4 绩效指标口径

| 指标 | 口径 |
|------|------|
| 年化收益 | $(1+r)^{250/n}-1$（**250 交易日**） |
| 年化波动 | 日波动 $\times\sqrt{250}$ |
| Sharpe | $(R_p-R_f)/\sigma_p$，$R_f$ = 同期 DR007（**不用 0**） |
| 最大回撤 | 日频净值峰谷 |
| Calmar | 年化收益 / \|MDD\| |
| 信息比率 | 相对 CBA00601 的超额年化 / 跟踪误差年化 |

## 11. ML / RL 的方法论纪律

> 目标团队是智能交易团队。这一节决定"你看起来像调包侠还是研究者"。

### 11.1 三个必须做的防泄漏措施

| 措施 | 具体做法 | 为什么 |
|------|----------|--------|
| **Purge** | 训练集与验证集之间，剔除标签窗口重叠的样本 | 预测未来 5 日收益时，相邻样本标签重叠，随机切分等于泄漏 |
| **Embargo** | 在验证集前额外留出 $h$ 天缓冲 | 特征工程若用了滚动窗口，仍有边界泄漏 |
| **样本外锁定** | 2024–2025 只跑一次 | 反复看测试集 = 隐式调参 |

时间序列切分示意：

```
[--------- 训练 2019-2022 ---------][gap][-- 验证 2023 --][gap][== 测试 2024-2025 ==]
                                    purge        embargo
```

### 11.2 评价指标（不能只报 Sharpe）

| 指标 | 含义 | 门槛 |
|------|------|------|
| IC（信息系数） | 预测值与实际变化的秩相关 | > 0.03 已属可用 |
| IC 衰减曲线 | $h=1,5,20,60$ 的 IC | 看信号半衰期 |
| 方向准确率 | 涨跌方向判对比例 | > 52% 有意义 |
| 分层收益单调性 | 按预测分 5 组，收益是否单调 | 单调性比绝对值更重要 |
| **Deflated Sharpe Ratio** | 对多重检验惩罚后的 Sharpe | > 0 才算显著 |
| 多 seed 方差 | 5 个 seed 的均值±标准差 | 方差大 = 不可靠 |

### 11.3 RL 的特殊纪律

1. **动作硬约束**：动作空间直接投影到 DV01/久期/杠杆上限内（action shielding），
   而不是只靠 reward 惩罚"期待它学会"；
2. **成本进奖励**：交易成本从奖励中扣除，否则学出高频抖动策略；
3. **真实序列**：环境用历史真实曲线序列，不用随机生成（否则学的是模拟器的偏差）；
4. **多 seed + 消融**：至少 5 个 seed；必做"去掉风险惩罚 / 去掉成本 / 离散vs连续动作"消融；
5. **诚实结论**：允许"RL 不如规则基线"，并定量解释原因（样本效率、非平稳、成本吃信号）。

### 11.4 与规则基线的对比框架

| 策略 | 说明 |
|------|------|
| Buy & Hold | 等权买入持有阶梯组合 |
| Rule-based | 2s10s 陡平 + Carry&Roll |
| ML overlay | ML 预测调仓 |
| RL | PPO / SAC 学到的策略 |
| Random | 随机仓位（下界） |

五个策略必须在**同一成本、同一约束、同一测试期**下比较，否则没有意义。
