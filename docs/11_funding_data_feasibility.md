# 资金操作信息的下一阶段可行性审计

状态：2026-11-28，**四份官方公告样例已读，完整历史序列尚未采集，预测与训练尚未启动**。

## 为什么选择这个入口

成本加回诊断未通过冻结预测门槛，因此停止原九特征、四档单次动作的继续优化；不把交易频率、奖励系数和网络结构换一遍继续搜索。下一步要检验的是新的信息来源是否可被当时的决策者获得，再单独定义它能够支持的任务。先做资金操作公告的数据审计，工程投入小于立刻建设期货保证金/换月账本，也有明确的发布时间核对对象。这是研究优先级判断，不是预言这些数据可以带来收益。

先限于央行逆回购操作及其明确公布的操作量、期限和利率。MLF、买断式逆回购等必须独立标记，不把不同工具混成“逆回购流动性”。暂不加盘口、社融修订值、文本模型或新闻情绪。

## 下一项工作的范围与通过标准

1. **只采集与核对数据。** 首批历史范围固定为 2018-12-01 至 2025-05-30，覆盖已有开发资料范围并保留初始回溯。归档原始页面、来源 URL、采集时间、正文散列、页面显示发布时间、公告业务日期、工具、期限、金额、利率和核验状态。不读取 2026 年保留前瞻行情。
2. **先证明覆盖。** 用独立银行间日历和来源公告清单核对期待日期，逐日区分有操作、明确零操作、休市/无需公告、缺失待核。日期不能由已抓到的公告反推；缺页、重复公告和更正均列清单，未知不能填零。非交易日发布的公告也保留，不因交易日过滤而丢失。
3. **时点从保守规则开始。** 页面时间和业务日期分列；特征最早于所显示发布日期后的下一银行间交易日使用，并另保留再延迟一个交易日的敏感性。只在有证据时收紧该规则。当前抓取的内容散列只锁定当前快照，不能证明历史版本未修订；无法确认的更正不回填当时特征。
4. **到期不靠想当然推算。** 操作期限不必等于节假日调整后的实际现金到期日。优先核对官方到期或起息信息；缺乏契约规则时只保留新操作量，禁止把“日历日期＋7”默认为净投放。初始存量不足时，净投放、存量特征均应缺失或设置充分预热期。
5. **数据准入是硬门槛。** 全部期待日期都有可审计状态；所有拟入模日期均具备金额/单位/期限/工具与因果可用时点；未知缺口不插值填零；人工核对零操作、混合工具、多期限、政策切换、长假和跨年样例。未来公告扰动不得改变过去输入。若无法完成，交付缺口报告并停止，不启动预测。

数据通过后，再冻结**一个**预测目标、一个持有期限、少量有经济含义的特征和一个线性基线。先设计跨年度、按发布时间滚动的开发比较，严格处理重叠标签；不重复把 29 个区间乘以路径数当作新增样本，也不按收益挑 5/10/20 日期限。需要估计相对资金利率/原曲线信息和简单持有对照的增量，及计入成本后的价值。旧开发时期即便拓宽仍不是独立确认；原前瞻期不能成为新任务的调参集。

## 预算与终止

本阶段交付为数据清单、完整性报告、可用时点契约及自动化检查，不申请 GPU、不训练 PPO/SAC、不扩网络。四份样例只说明有可读来源，不能声称完整数据已经到位。期货、盘口和宏观多来源扩展留待这项审计结束后再单独决定。
