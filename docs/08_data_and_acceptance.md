# 新增数据与交付审计

## 2026-11-28：先冻结新增信息检验

从[中金所历史下载入口](http://www.cffex.com.cn/cn/lssjxz.html)定位官方月度 ZIP，下载 2018-12 至 2025-05 共 78 份，保存原文件散列。覆盖 1,573 个交易日、15,684 条国债期货合约记录。T、TF、TS 各覆盖 1,573 日，TL 为 509 日；本次仅使用覆盖完整的 T 合约族。下载截至旧第 21 折内部留出期所需月份，未请求预留前瞻时期。原现券数据树不变，新增数据位于忽略目录 `datasets/cffex-eod-v1`。[覆盖清单](../reports/futures_data_coverage.json)

日期核验依据在下载前独立保存的旧数据商 T0 历史日期，完整日期清单及源散列已冻结。它是跨来源覆盖检查，不冒充官方节假日日历；缺整日、重复合约或少于两档有效期限立即失败。前瞻期仍使用独立银行间日历。[日期清单](../config/baselines/futures_sessions.json)

[中金所信息管理办法第十一条](http://www.cffex.com.cn/u/cms/www/202003/271646475n34.pdf)说明每日行情在交易日结束后发布，含成交量、持仓量、结算价等。没有取得逐历史日期的实际发布时间或修订版本：本次将报告日次日北京时间零点作为可用时点假设，只在下一决策日使用前一交易日及更早的报告，并另做延迟一个期货交易日的敏感性对照。这不足以证明历史逐笔时点完整性。

本批没有盘口买卖报价、深度、现券成交量、CTD/转换因子或历史逐日保证金调整。最近与次近有效到期合约的结算价差是跨月价差，不是 bid–ask、基差或可实现交易成本。无期货头寸进入现券账本；这些信息只作市场预测输入。真实盘口与保证金数据暂记“未核验可用”，不以日内高低价或当前保证金代替。

在原九个市场输入上，仅新增四项预定特征：T 全期限成交量相对 20 日中位数的对数、总持仓量五交易日变化、成交量/持仓量的对数、近月减次近月结算价差。没有挑选主力合约拼接收益。Ridge α=10、原 29 个拟合区间、原最后三分之一留出、训练段标准化及两个执行带保持不变，新增特征数量、数据散列、迟延敏感性和门槛在拟合新模型前冻结。[配置](../config/experiments/futures_signal_probe.json)

2 lot 至少两折同时降低相对原 Ridge 与拟合均值的预测 RMSE，且相对四项对照的三折中位标签增益均为正；1 lot 均非负；额外延迟一日后，相对原 Ridge 的中位增益在两档均非负。全部通过才考虑这三个旧开发窗口的连续账本，不增加 PPO 容量或更新轮数，不动前瞻期。标签从共同基准持仓出发，不能累加充当连续策略收益。

## 冻结后的实际结果

方案在提交 `875d950` 冻结后计算。2 lot 三折新模型 RMSE 为 4.411、2.984、3.790 bp；原 Ridge 为 4.061、2.933、3.861，拟合均值为 4.093、0.586、3.181。**0/3 折同时优于两个误差对照**（要求至少 2/3）。相对原 Ridge 的单区间净价值增量逐折为 −1.462、0、−0.290 bp；2／1 lot 三折中位数为 −0.290／−0.290 bp，相对零倾斜为 −0.776／−0.782 bp，相对拟合段连续固定策略选出的动作是 −0.522／−0.532 bp。

额外延迟一个期货交易日，相对原 Ridge 的两档中位增量仍为 −0.027／−0.025 bp。原特征基线预测全部先复现，1 lot 与 2 lot 使用同一个 2 lot 拟合模型和相同选档。主门槛与延迟门槛均未通过，**不追加连续回放、PPO 训练或前瞻检验**。[逐决策报告](../reports/futures_signal_probe.json) · [Python 图](../reports/delivery_futures.png)

这排除的是本次固定 T 活动度与跨月结算价差四特征组合，不能推出盘口或资金供需没有预测价值。也不宜继续在同三窗挑选更多期限/变换直到结果变好。下一阶段先获取真正带时点证据的报价深度或资金供需数据及覆盖清单，检查是否能对应当前五交易日现券执行目标；没有数据与预测证据，不增加网络或奖励搜索。
